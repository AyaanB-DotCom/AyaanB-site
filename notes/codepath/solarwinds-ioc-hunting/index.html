Educational security lab · CYB102 · Project 7

SolarWinds IOC Hunting

Searching proxy logs for known IOC IPs, confirming host/service context in Splunk, and checking the same indicators on VirusTotal.

Educational lab. Authorized CodePath Intermediate Cybersecurity exercise using course proxy logs and public reputation lookups. Findings below are taken from the submitted Project 7 PDF artifacts—not from a live production network.

01

Overview

This Project 7 submission correlates a list of suspicious external IP addresses against NetworkProxyLog02.csv in Splunk. Matched events reference SolarWinds Orion Core Services and internal hosts with Solar*-style names. Matching IPs were then checked on VirusTotal for vendor reputation context.

Course materials for this unit also describe a separate CSIRT handoff exercise (Catalyst case IR-2023-002, first responder Sam Johnson). That written triage / gap / recommendation analysis is not present in the PDF used for this archive entry, so it is left unpublished here.

02

Goals

IOC correlation
Search proxy telemetry for a provided indicator set and record match time, IP, and affected hosts or services.
Reputation research
Look up matched IPs in VirusTotal (and related sources) to add context beyond the raw log line.
Dashboard query
Capture the Splunk search used to surface the IOC set in one view.
