Educational lab · Ethical Hacking · Lab 01

Performing Passive Reconnaissance (4e)

Hands-on passive OSINT: Google search operators, WHOIS and DNS queries, theHarvester, and Maltego—then a short challenge recon write-up.

Lab report archive · October 4, 2026 · ~36 minutes on task

Educational lab. Authorized ethical-hacking coursework (Ethical Hacking, Fourth Edition — Lab 01). Chosen-organization identifiers from the challenge section are omitted.

01

Section 1 · Google Hacking Techniques

I started with Google search operators to see how each one shapes what you get back. Using site: limited results to a single domain (for example the New York Times). Using inurl: pulled pages whose URLs contained a chosen string instead. The operators each returned more specific result sets than a plain keyword search.

The differences I noticed in the search results were that they gave specific responses for each result. One scenario in which this can be useful is when I need to find info about a site, I can use the info dork.

I also looked for results that could help someone target an organization. One result found was articles about PHP errors in AWS. This might be used by hackers to create/search for future exploits, as they know that there was once a PHP vulnerability.

02

Section 1 · WHOIS and DNS

Next I ran a WHOIS lookup on a chosen domain and recorded registration details from the public record. The most recent update to the domain record was December 8, 2025.

I then used nslookup to query mail (MX) and name-server (NS) records. The MX query returned registrar mail-forwarding hosts; the NS query returned the domain’s authoritative name servers. That confirmed how the domain’s email and DNS were wired without contacting the target’s own servers beyond normal public DNS.

03

Section 2 · theHarvester and Maltego

For applied learning I ran theHarvester against the lab target domain using Bing and DuckDuckGo as backends. Both runs finished without returning IPs, emails, or hosts in the captured output—useful as a negative result: the tool path worked, but those sources had nothing indexed for that target at the time.

I also used Maltego to build a graph of name-server relationships and to list IP addresses, DNS names, and MX records for a demonstration domain. The graph view made the NS links obvious; the list view was better for scanning the set of discovered entities.

04

Section 3 · Challenge and Analysis

The challenge asked for organization details gathered through passive recon (name, domain, public presence, and related notes). Specific identifiers from that write-up are omitted here.

One scenario in which this information can be used in further ethical hacking endeavors is being able to find the email registered to the domain. An ethical hacker can then run OSINT tools against that email to find more information.
